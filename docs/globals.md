# Глобальные переменные

Все переменные доступны в любой точке сценария (Ink `VAR` — глобальные).
Имя ≤ 12 символов, только латиница — под лимит платформы. Значения по умолчанию
указаны такие же, как в `main.ink`.

## Счётчики

| Имя | Тип | Старт | Диапазон | Что делает |
| --- | --- | --- | --- | --- |
| `hp` | int | 100 | 0–100 | Здоровье. Атаки паука, электричество, падения. При 0 — концовка 30. |
| `oxygen` | int | 100 | 0–100 | Кислород. Тратится на переходы и травмы, +20 в финале после запуска насоса. При 0 — концовка 31. |
| `energy` | int | 0 | 0–1 | 1 после заливки топлива в `Hybrid_Energy_Plat`. Открывает запуск насоса и питание крана. |
| `scrap` | int | 2 | 0–99 | Универсальный ресурс ремонта: предохранитель, кабель, ловушка, жестянка для пса. |
| `fuel` | int | 0 | 0–9 | Топливо. Источники: паук на заправке (обмен или разбор). |
| `water` | int | 3 | 0–99 | Вода. Ключ к `dog_friend`, к обмену с пауком, пополняется у гидропоники. |
| `trust` | int | 0 | 0–99 | Доверие машин. `trust > 1` — робот разберётся со стражем шахты; `trust > 2` нужен для секретного финала. |
| `datachip` | int | 0 | 0–99 | Чипы «ЗАРЯ»: награда за исследование, квестовый предмет для лора. |
| `day` | int | 1 | 1–99 | Сутки. +1 при восстановлении кислорода. |
| `alert` | int | 0 | 0–99 | Тревога дронов. Растёт от грубых действий, открывает «умный» вариант с кабельной змеёй. |

## Флаги

| Имя | Тип | Старт | Когда становится true |
| --- | --- | --- | --- |
| `snake_fixed` | bool | false | кабель питания насоса сращён (`cable`) |
| `gen_on` | bool | false | энергоустановка запущена (`energy_plant`) |
| `gate_open` | bool | false | пёс пропускает к воротам (`dog`) |
| `dog_friend` | bool | false | пёс напоен и стал союзником (`dog`) |
| `spider_dead` | bool | false | страж шахты обезврежен (`spider`) |
| `know_truth` | bool | false | прочитан документ о «добровольцах» (`spider_loot`) |

## Служебное

| Имя | Тип | Старт | Значения |
| --- | --- | --- | --- |
| `ending` | int | 0 | `10` живой воздух, `11` добровольцы, `12` секрет, `20` снаружи, `21` вдвоём, `30` смерть, `31` удушье |

## Как это связано с финалом

```ink
=== epilogue ===
{ spider_dead && dog_friend && trust > 2: -> end_secret }   // 12
{ know_truth: -> end_know }                                // 11
-> end_good                                                 // 10
```

То есть секретная концовка требует трёх вещей одновременно: обезвреженный страж,
пёс-союзник и доверие машин выше 2 (проще всего — напоить и паука, и пса).

## Перенос в панель «Глобальные переменные»

1. Откройте `globals.csv` (Excel / Google Sheets / «Блокнот»).
2. «Добавить переменную» → имя из колонки `name`.
3. Тип: `int` → «Число», `bool` → «Флаг» / «Логическое».
4. Стартовое значение — колонка `default`.
5. Для флагов ставьте `false` (0), для чисел — как в таблице.

Порядок не важен, но удобно держать ресурсы сверху, флаги — снизу.
