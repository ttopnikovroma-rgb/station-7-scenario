# Сцена → сценарий: карта объектов

Сопоставление объектов из разделов «Загрузка героя», «Загрузка объектов» и
«Пользовательские эффекты» с узлами `main.ink`.

## Герой и базовая сетка

| В редакторе | Значение | В сценарии |
| --- | --- | --- |
| Сетка | 100 × 100 | масштаб двора «сто на сто шагов» |
| Текстура земли | `Текстура земли`, размер 100 | фон всех уличных сцен |
| Герой | `hero.glb` | единственный персонаж-игрок |
| Здоровье (HP) | 100 | переменная `hp = 100` |

| Объект | Узел | Программа состояний (что меняется) |

## NPC-мобы

| Объект | Узел | Поведение |
| --- | --- | --- |
| `pavuk` (на заправке) | `gas_station_talk` | нейтрален; отдаёт топливо за `water`, можно разобрать (`alert +2`) |
| `pavuk` (страж шахты) | `spider` | охраняет лут; обходится псом, ловушкой, роботом или силой |

## Теги в тексте

В `main.ink` у узлов стоят метки:

```ink
# scene:angar
# effect:ветер
```

* `# scene:<имя>` — какой объект/локация активна в этом узле;
* `# effect:<имя>` — какой пользовательский эффект включить.

Если платформа не использует теги, они ничего не ломают: Ink просто хранит их
рядом с текстом. Если использует — имена в тегах уже совпадают с именами
объектов из вашей сцены (`Oxygen_Pump`, `rt_70`, `like_dog`, `ветер`, `дождь`).

## Что стоит донастроить на сцене

1. Поставить `Oxygen_Pump` в центре, `Hybrid_Energy_Plat` — рядом, между ними
   провести `Cable_calm` / `cabel_snake` (визуальная причина квеста).
2. `gas_station` — у южной границы, рядом `pavuk` (первый, «торговый»).
3. Шахту обозначить `rock_2` + `column`, в глубине — ящики (можно `platform`).
4. `like_dog` — у ворот, `gate` — единственный выход за границу сетки.
5. `rt_70` и `hydropic` — как «ресурсные точки» по краям двора.
